# Qiyaam Moodley — Developer Portfolio

A deliberately expressive, editorial-style portfolio built to feel like a personal digital identity rather than a generic developer template.

## Design direction
Inspired by the supplied spectral-gradient reference: deep black, grain/noise, blurred colour fields, oversized typography, restrained UI, editorial spacing and motion.

## Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Redux Toolkit
- Context API
- Custom Hook
- Lazy-loaded routes
- Service layer
- Jest test examples
- Lucide icons
- Responsive design

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Updating the site
Most portfolio content lives in:
`src/data/portfolio.ts`

When a new achievement happens:
1. Add the project/achievement.
2. Add its stack.
3. Add the GitHub repository.
4. Add the live demo.
5. Update the milestone/journey.
6. Commit and redeploy.

## Important
The contact form is intentionally a frontend demo until we connect a real backend or form service.
